ARCHITECTURE / SYSTEM MAP

From decrypted guest code to native host execution.

PPSX33 is built around a native C++ / Qt 6 Widgets desktop application, a host-side core library, a generated Windows game executable and one unified runtime DLL. The source tree separates guest system services, PPU and SPU processors, RSX graphics, audio/video services and the Qt interface. The root CMakeLists.txt defines the actual build targets and output layout.

02 / BUILD TARGETS

What CMake actually builds

The root CMakeLists.txt is authoritative. Runtime sources are compiled into the unified runtime instead of being shipped as separate graphics DLLs.

DESKTOP

PPSX33.exe

Native C++ application using Qt 6 Widgets. Entry point and UI implementation live in src/ui_qt/.

CORE

ps3core.dll

Host-side core library for ELF loading, PPU lifting, project handling and core APIs.

RUNTIME

ps3rt.dll

One unified Windows runtime containing HLE, PPU import bridge, SPU interpreter, RSX state, FIFO, rendering and backend sources.

TOOL

Modify.exe

Per-game launcher target built from src/tools/modify/modify_main.cpp.

CLI

ps3_cli

Command-line entry point in src/cli/ps3_cli.cpp, when enabled by the build configuration.

GRAPHICS

Vulkan + OpenGL

Vulkan 1.2 is the default host path. OpenGL backend sources are included as a secondary path. Direct3D 11 is removed.

03 / SOURCE TREE

Subsystem ownership

This is a guided map of the current src/ tree. See STRUCTURE.md for the detailed file-level listing.

src/core/

Guest system and host core

ELF loaders, guest memory, filesystem/VFS, HLE kernel, import/NID mapping, project orchestration, statistics and the ps3core public API.

src/processor/PPU/

PowerPC processor unit

PPU disassembly, interpreter, JIT support, lifter, translated import bridge and generated-code runtime headers.

src/processor/SPU/

Synergistic processor unit

SPU interpreter and JIT paths, local-store model and SPU execution state.

src/RSX/

Graphics processor

Device state, guest memory, FIFO, method tables, dispatch, draw batches, framebuffer, textures, shader decode/binding/compilation, presentation and Vulkan/OpenGL backends.

src/games-stuff/

Audio and video services

Audio decoders, host audio drivers, mixer and voice state, plus video demuxing, decoders, timing, color conversion and presentation.

src/ui_qt/

Qt 6 desktop application

Main window, native bridge, settings, terms/legal dialogs, job worker, app version and Qt resources.

04 / OUTPUT LAYOUT

One runtime, clearly staged

Current build output is organized under build/dist/. The runtime directory is for headers, not duplicate runtime DLLs.

build/dist/PPSX33.exe

Qt 6 desktop application.

build/dist/ps3core.dll

Host-side ELF and project core.

build/dist/ps3rt.dll

Unified runtime for generated game builds.

build/dist/vulkan-1.dll

Vulkan loader staged by the CMake helper when available.

build/dist/Modify.exe

Per-game Modify launcher.

build/dist/runtime/

Generated-code/runtime headers only. No duplicate DLL or LIB bundle.

05 / GRAPHICS AND VALIDATION

Host presentation is not title rendering.

Vulkan 1.2 is the default presentation backend. OpenGL remains a secondary backend with parity still in progress. Guest PUT progress, correct FIFO processing, resource state and title-authored shaders are required for real game scenes.

1
PPU correctness

Validate instruction semantics, branch recovery, imports and guest state.

2
SPU and DMA

Validate local store, channels, MFC tags, completion order and scheduling.

3
RSX / GCM

Trace guest GET/PUT, FIFO methods, shaders, textures, render targets and synchronization.

4
End-to-end title evidence

Record reproducible boot, rendering, input, audio and sustained-run results. Static lift counts and assist draws are not compatibility proof.

Diagnostic flags: PS3RT_STRICT_FAULT=1 enables strict guest-PC fault handling. PS3RT_INJECT_SEED=0 disables boot FIFO assist. Assist draws validate only the host graphics path.
