OPEN SOURCE · FULL RECOMPILATION

PlayStation 3.
Recompiled for a new host.

PPSX33 is an experimental PlayStation 3 full recompiler. It lifts supported code from decrypted ELF input into native Windows builds and develops the runtime services required by real titles. The desktop application is a native C++ / Qt 6 Widgets program. Its core pipeline uses ps3core.dll for ELF analysis and PPU lifting, then builds a native Windows game executable linked with the modular ps3rt runtime. Vulkan 1.2 is the current default host presentation path; title-authored RSX rendering remains incomplete.

PROJECT SCOPE

Experimental by design. Honest by default.

PPSX33 accepts decrypted ELF input only. It does not decrypt retail games, distribute game content or keys, or promise universal compatibility. Vulkan 1.2 is the default host graphics path. OpenGL is a secondary backend with parity still in progress. Direct3D 11 has been removed. Use only software you are legally entitled to use.
