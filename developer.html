Meet the developer behind PPSX33.

NotY215 is the project identity behind PPSX33, an experimental PlayStation 3 full-recompiler project focused on translating guest code and building the Windows runtime needed to execute it. This page brings together the project source, engineering direction, and public GitHub activity.

ABOUT THE WORK

Systems, runtime and graphics research

PPSX33 is being developed toward full recompilation: supported PPU regions are translated into generated native code, then linked against host runtime services. The project also works on LV2 and PRX services, SPU/MFC/DMA behavior, and RSX/GCM graphics.

The current desktop interface is native C++ with Qt 6 Widgets. ps3core.dll provides ELF analysis and lifting functionality, while the generated Windows executable uses the unified ps3rt.dll runtime. Vulkan 1.2 is the default host presentation path.

Engineering principles

  • Report implemented code separately from verified behavior.
  • Use reproducible logs and title-specific evidence for compatibility claims.
  • Keep architecture, ownership and build documentation aligned with the source tree.
  • Prioritize correctness in control flow, guest runtime behavior and title-authored rendering.
  • Do not treat a successful lift, build, clear or diagnostic draw as proof of playability.
