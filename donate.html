SUPPORT INDEPENDENT DEVELOPMENT

Help keep the code moving.

Every feature, fix, test and release takes focused time. If you enjoy my work on PPSX33, Vayu and other open-source projects, a small gift can help me keep building and make that work more sustainable.

WHY YOUR SUPPORT MATTERS

Programming takes more than typing code.

Independent development is a long-term effort. Designing architecture, writing and reviewing code, reproducing bugs, testing builds, documenting changes and maintaining websites all take hours of concentration. My computer also needs electricity to run during development, builds and testing, and the tools and hardware need ongoing care.

I work on these projects because I want to create useful software and share the results. Donations help cover practical costs, give me more room to spend time on development, and provide encouragement to continue improving the projects instead of having to put that time elsewhere. There is no obligation and no amount is too small to be appreciated.
