ABOUT / PROJECT BRIEF

Recompilation is a systems problem.

PPSX33 is an experimental PlayStation 3 full recompiler. It translates supported guest code from decrypted ELF input into native Windows builds and reconstructs the runtime contracts needed for execution. The desktop frontend is native C++ / Qt 6 Widgets, with ps3core.dll handling ELF processing and PPU lifting. Generated game executables use the unified ps3rt.dll runtime. The implementation remains experimental and does not establish general game compatibility.

SCOPE & PRINCIPLES

What counts as progress?

IN SCOPE

Engineering direction

Decrypted ELF inspection, PPU lifting, generated C++, native Windows build integration, LV2 and PRX/NID HLE, SPU/MFC/DMA, and RSX/GCM. The Qt 6 desktop application is the native host interface. The CMake build defines PPSX33.exe, the ps3core and ps3rt libraries, and the Modify launcher; there is no separate graphics-module DLL bundle. Vulkan 1.2 is the default host graphics path; OpenGL parity remains in progress.

NOT A CLAIM

Compatibility requires evidence

A successful lift, generated executable, diagnostic draw or Wikipedia game result does not prove that a title runs correctly. Retail decryption is out of scope. Direct3D 11 has been removed. The runtime is provided through the unified ps3rt.dll.

Evidence rule

Compatibility claims should identify a reproducible test, known build, specific title and observed result.
