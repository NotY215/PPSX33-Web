03 / RECOMMENDED CONFIGURATION

More headroom.
Smoother presentation.

For larger FIFO and texture traffic, the project recommends additional graphics memory, system memory and SSD storage.

RECOMMENDED ≠ REQUIRED

These are recommendations for smoother presentation, not mandatory minimums.

GPU MEMORY2 GB+Discrete GPU with current vendor drivers and Vulkan 1.1 support.
SYSTEM MEMORY8 GB+For guest execution and host-side buffers.
STORAGESSDRecommended for game data and runtime logs.

05 / BUILDING PPSX33 ITSELF

Building the toolchain is a different job.

The runtime requirements above apply to running a recompiled game. Building the PPSX33 desktop application and lift projects uses a separate development environment.

IMPORTANT / COMPATIBILITY

Meeting requirements does not guarantee a game will run.

These specifications describe the current host window and presentation path. Game execution still depends on PPU, SPU, RSX/GCM and system-service implementation. A title may open a window and still fail to boot or render correctly.
